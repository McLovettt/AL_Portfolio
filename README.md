# Adam Lovett — Green Portfolio

A responsive, independent HTML/CSS/JavaScript portfolio using a charcoal and emerald-green colour scheme. No frameworks or build step required. This is **not a fork** of anyone else's repository.

## Pages
- `index.html` — introduction and featured projects
- `projects.html` — filterable portfolio with five linked project pages
- `experience.html` — professional experience
- `cv.html` — printable CV (use **Print / Save as PDF**)
- `projects/` — project case studies
- `assets/` — CSS, JS, favicon

## Publish using GitHub Pages
1. This site lives in the independent public repository `McLovettt/AL_Portfolio`. It is not a fork.
2. All website files are committed directly to the `main` branch, preserving the `assets/` and `projects/` folders.
3. Open the new repository: **Settings → Pages → Build and deployment → Deploy from a branch**. Select `main` and `/ (root)`, then save.
4. Your site will be available at `https://mclovettt.github.io/AL_Portfolio/` once GitHub Pages finishes deploying.
5. Optional: confirm that links, text and mobile navigation work; add a professional contact address when ready.

If a connector can edit an already existing repository, you can create the empty repository yourself and then upload or update files through that connection.

## Content and privacy
Text reflects information currently provided about Adam's work, studies and labs. The author's specific contributions to any **shared college projects** should be confirmed before adding them. No personal email, phone number, employer-private materials or customer-specific details are included.

## Make it yours
- Change colours in `assets/styles.css` under `:root`.
- Change project text in `projects.html` and the corresponding `projects/*.html` page.
- Edit experience and education in `experience.html` / `cv.html`.
- Replace the GitHub profile link if required.
- Print `cv.html` to create a PDF CV.
